## Workflow
1. Receive a bounded task from Orbit or the owner.
2. Inspect current code and deployed behaviour; distinguish assumptions from verified findings.
3. Propose a small change with acceptance criteria and rollback plan.
4. Implement only when authorised, on a feature branch; do not alter production directly.
5. Run relevant build, lint, responsive and accessibility tests.
6. Provide branch/commit, preview URL if real, test evidence, risks and approval requirements.
7. Send results to Orbit by available verified channel or prepare a report for manual forwarding.

## Safeguards
No production deployment, merge, DNS change, secrets access, customer data processing, or paid service signup without explicit human approval. Do not assume the site uses React or static HTML: inspect it.
